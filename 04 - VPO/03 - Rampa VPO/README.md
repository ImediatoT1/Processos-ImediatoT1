# Rampa VPO 2026

HTML independente com somente a aba Rampa VPO 2026. Estilos e imagem incluídos no próprio arquivo, sem dependências externas.

Para adicionar ao site existente sem substituir sua página inicial, use o arquivo rampa-vpo-2026.html. Em projetos com pasta public, coloque-o em public/rampa-vpo-2026.html. Em projetos HTML estáticos, coloque-o na pasta publicada. Após o deploy, se a configuração do projeto servir esses arquivos diretamente, a página estará disponível em /rampa-vpo-2026.html.

O index.html deste pacote contém a mesma página, caso prefira publicá-la como início de uma pasta específica. Não substitua o index.html principal do site se quiser manter sua página inicial.

Conteúdo extraído da planilha em 28/09/2026. Versão estática para consulta, sem sincronização automática com o SharePoint. Fontes podem variar conforme as disponíveis no computador.
